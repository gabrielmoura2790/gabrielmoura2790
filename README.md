#### 🚀 Projeto em destaque

**IDX Brasil / Base Digital, plataforma de gestão imobiliária**  
*Next.js · TypeScript · PostgreSQL · Prisma · CASL · AWS EventBridge · RabbitMQ · Vitest*

Plataforma que unificava CRM com IA, chat integrado ao WhatsApp, gestão de imóveis, propostas, contratos e eventos de pré-lançamento ao vivo, para corretores, imobiliárias e construtoras. Avaliada em R$10M em rodada pré-seed.

- Módulo de eventos ao vivo com pagamentos simultâneos via PIX, que transacionou **mais de R$104M em VGV** sem cobrança duplicada
- Autorização granular por cargo e recurso com CASL, aplicada em rotas, server actions e UI, com **mais de 1.300 testes automatizados**
- Motor de distribuição automática de leads com SLA agendado no EventBridge, cobrindo **16 origens de entrada**
- Schema com mais de 106 modelos atendendo três perfis de negócio distintos
- Agente SDR com OpenAI + WhatsApp que qualifica leads antes do contato humano
